2. 院校详情头：删除 `school-focus-stats` 整条（邮件/待处理/紧急/最新邮件）。
3. 学生信息条：删除「任务编号：xxx」，保留「张明 · 2027 Fall」（申请季属主体信息）。

   `official-records`（申请状态页、材料清单页检查记录），仅保留申请系统快照区。
   → 连带删除「上传监控记录」按钮、`monitorRecordModal`、`openRecordUpload/submitRecord`。

7. 清理对应废弃 CSS，静态资源版本号 v1.0 → v1.1。

## 约定

- 用户对页面信息密度敏感：**优先删小标签/数字 chip，而不是新增**。
- 删除数据展示区时，要连带检查并清理"写入该区域的录入入口"（否则出现点击无反馈的死按钮）。
- 本项目 JS/CSS 为 LF 换行、无构建；改完用 `node --check` 校验语法，
  再用最小 DOM 桩 eval 一遍渲染函数做冒烟（可查渲染产物里是否还有被删标签）。

## 监控详情页四轮：两个面板对称

「上传截图」原在官网监控正文里的 `snapshot-title-row`，位置与邮件面板头部的「更新邮件」不对齐。改为：

- 按钮移入 `.channel-panel-head`（HTML 静态声明，带 `data-pbs-permission="monitor_site_manage"`），
  与「更新邮件」左右对称。
- `renderOfficial()` 去掉 `<section class="snapshot-section">` 与 `snapshot-title-row`，
  直接返回 `<div class="snapshot-grid">`。两个面板正文现在都是"无区块标题、直接铺内容"。
- 清理 CSS：`.snapshot-section`、`.snapshot-title-row`（含 h4/p 子规则）全部删除。
- 资源版本号 v1.3 → v1.4。

### 经验
- 面板类组件里，**操作按钮统一放面板头部**（与标题同一行），正文只放内容列表；
  不要既有面板头又在正文里再塞一个带按钮的小标题行，会破坏左右面板的对称感。

### 经验
- 固定枚举改自由输入时，匹配键要从"稳定 key"换成"用户输入内容"，并处理重复（按标题去重）与空值。
- Node 冒烟桩里 `window` 是自定义对象，`pbsMonitor` 挂在 `global.window.pbsMonitor`，不是 `global.pbsMonitor`。
