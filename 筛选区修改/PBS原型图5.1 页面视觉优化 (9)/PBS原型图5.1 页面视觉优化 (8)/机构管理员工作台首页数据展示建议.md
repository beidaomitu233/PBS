# 机构管理员工作台首页数据展示建议

> 基于《PBS原型图5.1 页面视觉优化》中的「管理员工作台 - 留学申请管理系统.html」原型，结合机构管理、人员管理、项目/交付/网申/文书等相关页面，给出机构管理员（本机构租户内的最高管理者）工作台首页的数据展示建议。

---

## 一、角色定位与数据边界

| 项目 | 说明 |
| --- | --- |
| 角色 | 机构管理员：负责本机构整体经营与交付质量，不直接处理具体任务，核心诉求是「看全局、抓异常、做决策」 |
| 数据范围 | 仅限本机构租户内数据（区别于平台超管的多机构视角）；可按部门（美国部/英国部/澳洲部/欧洲部）下钻 |
| 首页原则 | ① 30 秒内掌握机构健康度；② 异常事项一眼可见、一键可达；③ 经营/交付/风险/人员四条主线均衡覆盖 |

## 二、首页信息架构建议（自上而下）

```
① 标题栏：欢迎语 + 今日待办汇总 + 数据更新时间 + 导出报表
② KPI 指标卡（第一屏核心，建议 5~6 张）
③ 预警与待办区（DDL 紧急度看板 / 异常项目 / 待审批）
④ 经营与交付趋势图（签约趋势、完成率环比、部门分布）
⑤ 团队负载与人效（人员维度，原型目前缺失，建议新增）
⑥ 系统消息 / 机构公告
⑦ 快捷操作
```

## 三、各区域数据建议明细

### ① KPI 指标卡（建议 5~6 张）

| 指标 | 口径 | 展示形式 | 点击下钻 |
| --- | --- | --- | --- |
| 本月新增项目 | 本月创建的项目数，含环比 | 大数字 + 环比箭头 | 项目池列表（按本月筛选） |
| 本月签约金额 | 本月已签合同金额 + 目标完成率 | 大数字 + 目标进度条 | 签约明细 |
| 进行中项目数 | 状态为进行中的项目总数 | 大数字 + 各部门构成 | 我的项目列表 |
| 项目完成率 | 已完成 / 项目总量（当月或累计可切换） | 百分比 + 进度条 | 结项归档列表 |
| 待审核交付 | 待审核交付物数，**标注超期数** | 大数字 + 「需加急」红标 | 文书审核列表 |
| 本月新增学生 | 本月建档学生数 + 环比 | 大数字 | 学生档案列表 |

> 说明：原型现有 4 张卡（新增项目、待审核交付、签约金额、完成率），建议补充「进行中项目数」和「新增学生数」，补齐「客户/存量」视角；签约金额建议同时展示目标完成率进度条而非仅箭头。

### ② 预警与待办区（沿用并强化原型 DDL 紧急度看板）

建议保留「紧急 / 重要 / 常规」三列看板，并明确各列的数据来源与规则：

| 列 | 纳入规则（建议口径） | 典型卡片 |
| --- | --- | --- |
| 紧急（红） | 已超时 / 今日截止 / 48 小时限时 | 交付审核超时、项目进度异常、合同待审批、网申 DDL ≤ 3 天 |
| 重要（黄） | 3 日内到期 / 待确认 / 催办中 | 培训安排、月报催办、质量抽查、选校方案待确认 |
| 常规（绿） | 7 日内到期 | 周报提交、新人入职准备、预算终审 |

**补充建议：**
- 增加「网申 DDL」专项卡片：原型中已有网申任务模块，网申截止日是硬时间窗，建议单列或在紧急列固定置顶；
- 每张卡片展示：对象（学生-院校项目）、事项类型、剩余时间/已超时、责任人、一键跳转处理；
- 列头显示计数徽章（如 紧急 3 / 重要 3 / 常规 3），与系统消息数联动。

### ③ 经营与交付趋势图

| 图表 | 维度 | 建议 |
| --- | --- | --- |
| 项目完成率环比（原型已有） | 按月，当月 vs 上月 | 保留；建议支持切换「近 6 月 / 近 12 月」 |
| 签约金额趋势（建议新增） | 按月签约额 + 目标线 | 与 KPI 卡「目标完成 63%」呼应，管理员最关心的经营指标 |
| 各部门项目数量分布（原型已有） | 部门 × 项目数 × 完成率 | 保留；建议增加点击部门下钻到该部门项目列表 |
| Offer / 录取结果统计（建议新增） | 本季已获 Offer 数、录取率 | 留学机构核心成果指标，适合首页露出 |

### ④ 团队负载与人效（原型缺失，建议新增模块）

机构管理员需要判断人力是否匹配业务量：

| 指标 | 说明 |
| --- | --- |
| 顾问/文案负载 | 每人在办项目数 Top 列表，超载（如 >8 个）标红 |
| 交付及时率 | 各部门按期交付率，低于阈值（如 90%）预警 |
| 人员动态 | 本月新入职 / 离职 / 待开通账号数（对接人员管理页） |
| 待分配任务 | 项目池/订单池中尚未指派顾问的单量 |

### ⑤ 系统消息 / 公告（原型已有弹窗，建议改为常驻侧栏或页面区块）

- 按级别分色：红（超时/异常）、黄（催办/提醒）、灰（一般通知）；
- 消息与待办联动：点击消息直接跳转到对应处理页，处理完成自动置为已读；
- 增加「机构公告」位：管理员可向全员发布公告（原型的培训通知、政策解读可归入此类）。

### ⑥ 快捷操作（原型已有 4 项，建议按需扩展）

保留：审核交付、人员管理、数据报表、系统设置；
建议增加：新增学生建档、新增项目、角色权限管理、操作日志审计（与原型已有页面一一对应）。

## 四、数据口径与刷新规则建议

| 项目 | 建议 |
| --- | --- |
| 刷新频率 | KPI 与待办类：准实时（操作触发 + 定时 5 分钟）；趋势图表：每小时/每日 |
| 数据更新时间 | 页面右上角显式展示「数据更新于 HH:mm」，避免决策基于过期数据 |
| 时间口径统一 | 「本月」默认自然月；环比=上月同期；所有卡片口径在 tooltip 中说明 |
| 空态与异常 | 无数据显示 0 与空态插画，接口异常显示「加载失败，点击重试」，不留白 |
| 阈值可配置 | 超期天数、负载上限、及时率阈值等建议在系统设置中可配 |

## 五、权限与交互建议

1. **数据可见性**：机构管理员可见本机构全部数据；部门主管角色仅见本部门（同一工作台模板按权限裁剪）；
2. **下钻链路**：所有 KPI 卡、图表、消息均支持点击跳转到对应列表页并携带筛选条件（原型中目前用 alert 演示，落地时需替换为真实路由）；
3. **首屏优先级**：KPI + 紧急待办必须在首屏完整可见（不做折叠）；趋势图表与人效模块可后置；
4. **导出报表**：导出内容与首页口径一致（KPI 汇总 + 部门明细），支持 Excel/PDF；
5. **响应式**：管理场景以 PC 为主，但 KPI 卡与待办建议适配平板竖屏（grid 4→2 列降级）。
